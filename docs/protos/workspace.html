workspace_v4_definition.proto

Package ldtx.workspace.v4

CanvasConfiguration

Represents Canvas in the Workspace sidebar.

FieldTypeLabelDescription
landscape_profile_id string The profile identifier selected for the Landscape Canvas.
portrait_profile_id string The profile identifier selected for the Portrait Canvas.
frame_rate uint32 The output frame rate in frames per second.
landscape_video_bit_rate uint32 The target video bit rate for the Landscape Canvas in bits per second.
portrait_video_bit_rate uint32 The target video bit rate for the Portrait Canvas in bits per second.
pts_master_video_input_device_internal_id uint64 optional The Video Input Device internal ID used as the master clock for video presentation timestamps. When absent, the runtime default applies.

OutputConfiguration

Represents Output in the Workspace sidebar.

FieldTypeLabelDescription
records_landscape bool Whether the Landscape output is recorded.
records_portrait bool Whether the Portrait output is recorded.
streams_to_youtube bool Whether output is streamed to YouTube.
youtube_ingest_mode YouTubeIngestMode The layout and protocol used for YouTube ingest.
output_folder_path string optional The folder where recordings are written. When absent, the runtime default output folder applies.
recording_custom_fields map<string, string> map Additional fields written with recordings, keyed by their field names.

ProgramDefinition

Defines the Video Layer order for one Program. A Video Layer is either a Video Input Device or a Video Component.

FieldTypeLabelDescription
internal_id uint64 The Workspace-local identifier for this entity. Its most significant bit is zero; bits 62 through 15 encode milliseconds since the Unix epoch, and bits 14 through 0 are uniformly random.
display_name string The name of this Program shown on the selector.
landscape_video_layer_internal_ids uint64 repeated The Video Input Device or Video Component internal IDs in Landscape Video Layer order.
portrait_video_layer_internal_ids uint64 repeated The Video Input Device or Video Component internal IDs in Portrait Video Layer order.

WorkspaceDefinitionV4

Version 4 WorkspaceDefinition.

FieldTypeLabelDescription

canvas_configuration CanvasConfiguration Represents Canvas in the Workspace sidebar.
output_configuration OutputConfiguration Represents Output in the Workspace sidebar.
input_devices InputDeviceWrapper repeated Represents Input Devices in the Workspace sidebar.
video_components VideoComponentWrapper repeated Represents Video Components in the Workspace sidebar.
visions VisionWrapper repeated Represents Visions in the Workspace sidebar.

YouTubeIngestMode

The layout and protocol used for YouTube ingest.

ValueNumberDescription
YOUTUBE_INGEST_MODE_UNSPECIFIED 0 No YouTube ingest mode is specified. The runtime uses Landscape RTMPS.
YOUTUBE_INGEST_MODE_LANDSCAPE_RTMPS 1 Sends the Landscape output using RTMPS ingest.
YOUTUBE_INGEST_MODE_PORTRAIT_RTMPS 2 Sends the Portrait output using RTMPS ingest.
YOUTUBE_INGEST_MODE_DUAL_RTMPS 3 Sends Landscape and Portrait as separate RTMPS streams.
YOUTUBE_INGEST_MODE_LANDSCAPE_HLS 4 Sends the Landscape output using HLS ingest.
YOUTUBE_INGEST_MODE_PORTRAIT_HLS 5 Sends the Portrait output using HLS ingest.
YOUTUBE_INGEST_MODE_LANDSCAPE_DASH 6 Sends the Landscape output using DASH ingest.
YOUTUBE_INGEST_MODE_PORTRAIT_DASH 7 Sends the Portrait output using DASH ingest.

workspace_v4_preferences.proto

Package ldtx.workspace.v4

BasicTransform

The basic transform applied to a Video Layer, which is a Video Input Device or a Video Component.

FieldTypeLabelDescription
translation_x float The horizontal translation in coordinates normalized to the Canvas that renders this Video Layer, in the range [0, 1].
translation_y float The vertical translation in coordinates normalized to the Canvas that renders this Video Layer, in the range [0, 1].
scale_x float The horizontal scale.
scale_y float The vertical scale.
top_inset float The top inset as a fraction of this Video Layer's statically defined content height, in the range [0, 1].
right_inset float The right inset as a fraction of this Video Layer's statically defined content width, in the range [0, 1].
bottom_inset float The bottom inset as a fraction of this Video Layer's statically defined content height, in the range [0, 1].
left_inset float The left inset as a fraction of this Video Layer's statically defined content width, in the range [0, 1].

portrait_audio_channel_muted map<uint64, bool> map Whether each Portrait Audio Input Device is muted, keyed by Input Device internal_id.
portrait_video_layer_transforms map<uint64, BasicTransform> map The transforms for Portrait Video Layers, keyed by Video Input Device or Video Component internal_id.
portrait_video_layer_muted map<uint64, bool> map Whether each Portrait Video Layer is muted, keyed by Video Input Device or Video Component internal_id.

portrait_master_volume double The Portrait master volume in decibels.

ClockComponent

A Video Component that renders the current date and time.

FieldTypeLabelDescription
internal_id uint64 The Workspace-local identifier for this entity. Its most significant bit is zero; bits 62 through 15 encode milliseconds since the Unix epoch, and bits 14 through 0 are uniformly random.
display_name string The name of this Video Component shown in the Workspace sidebar.
width float The Clock width normalized to the Landscape Canvas width, in [0, 1].
height float The Clock height normalized to the Landscape Canvas height, in [0, 1].
shows_date bool Whether the rendered Clock includes the date.
shows_seconds bool Whether the rendered time includes seconds.
uses_24_hour_time bool Whether the rendered time uses a 24-hour clock.
utc_offset_minutes sint32 optional The fixed offset from UTC in minutes. When absent, the Clock uses the system time zone.
foreground_color ExtendedSrgbColor The color of the rendered date and time text.
background_color ExtendedSrgbColor The background color of this Clock.
outlines ClockTextOutline repeated The text outlines rendered around the Clock text, in order.

OcrVision

An image-analysis request that recognizes text in an image.

FieldTypeLabelDescription
internal_id uint64 The Workspace-local identifier for this entity. Its most significant bit is zero; bits 62 through 15 encode milliseconds since the Unix epoch, and bits 14 through 0 are uniformly random.
display_name string The name of this Vision shown in the Workspace sidebar.
triggers VisionTriggerWrapper repeated The conditions that automatically trigger this Vision.
input_device_internal_id uint64 oneof source Uses this Input Device as input.
region_of_interest VisionRegionOfInterest The region of the input image in which Vision performs the request.
accurate bool Whether text recognition prioritizes accuracy over speed. False uses the fast level.
recognition_languages string repeated The BCP 47 languages Vision detects, in priority order. An empty list enables automatic language detection.
uses_language_correction bool Whether Vision applies language correction during text recognition.
custom_words string repeated The words that supplement Vision's lexicon during word recognition. Vision uses these only when language correction is enabled.
minimum_text_height float optional The minimum text height relative to input image height. When absent, the Vision Framework default applies.

height float The height, in the range [0, 1].
